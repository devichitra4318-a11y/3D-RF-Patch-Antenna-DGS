# 3D RF Design – Rectangular Patch Antenna with DGS

## 📌 Project Overview

This college project presents a 3D design illustration of a **Rectangular Microstrip Patch Antenna with Defected Ground Structure (DGS)** for an operating frequency of 5.8 GHz.

The design is intended for study using **CST Studio Suite**, an electromagnetic simulation tool used in RF and microwave engineering.

The antenna structure includes a rectangular copper patch, a microstrip feed line, an FR-4 dielectric substrate, and a ground plane with three rectangular slots.

## 🎯 Project Objectives

- To understand the basic structure of a microstrip patch antenna.
- To study the design of an antenna operating at 5.8 GHz.
- To understand the purpose of a Defected Ground Structure (DGS).
- To identify the different layers and materials used in antenna design.
- To explore 3D electromagnetic modeling using CST Studio Suite.

## 🧩 Main Components

### 1. Rectangular Patch

The copper patch acts as the main radiating element of the antenna.

### 2. Microstrip Feed Line

The feed line provides a path for supplying the RF signal to the patch.

### 3. FR-4 Substrate

The FR-4 dielectric material supports the patch and separates it from the ground plane.

### 4. Ground Plane with DGS

The ground plane contains three rectangular slots. These slots disturb the ground-current distribution and can influence antenna performance.

### 5. Electric Field Distribution

The design illustration shows the electric field distribution around the patch at 5.8 GHz. The field pattern should be verified through an actual electromagnetic simulation.
